# Process Mining Workbench

Программный модуль автоматизированной реконструкции и интерактивной визуализации графов бизнес-процессов по журналам событий.

## Возможности модуля

1. **Загрузка и разбор журналов событий:** поддержка форматов `CSV` (автоопределение разделителей `,` и `;`), `XES` (стандарт IEEE 1849-2016 с пространствами имен `concept:name`, `time:timestamp`, `org:resource`) и `JSON` (плоский массив событий или список трасс).
2. **Сопоставление полей (Mapping):** интерактивный выбор колонок `Case ID`, `Activity`, `Timestamp` и `Resource` с эвристическим автоподбором при загрузке пользовательских логов и отсевом некорректных строк.
3. **Алгоритмическая реконструкция процесса:**
   * Построение ориентированного графа прямого следования (`Directly-Follows Graph`, `DFG`) со сложностью $O(N)$.
   * Расчет показателя направленной зависимости (`Heuristic Miner`) для каждого перехода: $(|a > b| - |b > a|) / (|a > b| + |b > a| + 1)$.
   * Выделение стартовых и завершающих операций, расчет медианного времени выполнения и фиксация циклов возврата (`Rework`).
4. **Интерактивная фильтрация шума:** ползунки отсечения редких узлов и переходов в реальном времени, а также быстрые пресеты (`Все связи`, `Оптимум 5%`, `Магистраль`).
5. **Визуализация и экспорт:** интерактивный граф на базе `Cytoscape.js` и раскладки `Dagre`, переключение метрики на ребрах (частота или средняя длительность), инспектор операций и переходов, светлая и темная темы оформления, экспорт схемы в `BPMN 2.0 XML` (стандарт ISO/IEC 19510) и `PNG`.

## Стек технологий

* **Серверная часть:** Python 3.10+, `FastAPI`, `Uvicorn`, `Pandas`, стандартная библиотека `xml.etree.ElementTree`.
* **Клиентская часть:** `HTML5`, `JavaScript (ES6+)`, `Cytoscape.js`, `Dagre`, `Tailwind CSS`, цветовая система Radix OKLCH (локальные библиотеки в `frontend/libs/`, работает без доступа к интернету).

## Установка и запуск

### Требования
* Python 3.10 или выше

### Шаги запуска

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <URL_репозитория>
   cd <папка_проекта>
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите сервер:
   ```bash
   python backend/app.py
   ```
   Под Windows можно также запустить файл `Запустить_веб_модуль.bat`.

4. Откройте в браузере:
   * Главная страница: `http://127.0.0.1:8000/`
   * Рабочая среда Workbench: `http://127.0.0.1:8000/workbench`

## REST API

* `GET /api/v1/health` : проверка состояния сервиса
* `GET /api/v1/logs/presets` : список встроенных наборов данных
* `POST /api/v1/logs/load-preset/{preset_id}` : загрузка предустановленного лога и построение графа
* `POST /api/v1/logs/upload` : загрузка пользовательского файла `.csv`, `.xes` или `.json`
* `POST /api/v1/logs/map` : сопоставление колонок для табличных и JSON-логов
* `POST /api/v1/graph/build` : пересчет графа по новым порогам фильтрации
* `GET /api/v1/graph/export?format=bpmn` : выгрузка модели в `BPMN 2.0 XML` или `JSON`
